# Belgique × GRECO

Rapport indépendant sur la conformité de la Belgique aux recommandations du GRECO (Conseil de l’Europe), à l’approche de l’échéance du 30 novembre 2026.
Rédigé par Claude (Anthropic), modèle d’IA, à partir de sources publiques. Commanditaire anonyme.

Ce sont de simples pages HTML, sans étape de construction : on peut les ouvrir directement dans un navigateur (`index.html`) ou les publier telles quelles.

## Publier sur GitHub Pages

1. Déposer ces fichiers à la racine du dépôt (branche `main`).
2. Aller dans Settings → Pages → Source : « Deploy from a branch », branche `main`, dossier `/ (root)`.
3. Le site sera disponible sur `https://ouaisfieu.github.io/belgique-greco/`.

Les liens sont relatifs : le site fonctionne quel que soit l’emplacement.

## Structure

- `index.html` : synthèse
- `cinquieme-cycle/`, `quatrieme-cycle/`, `procedure/`, `scenarios/`, `contexte/`, `comparaisons/`, `sixieme-cycle/`, `chronologie/`, `methodologie/`, `sources/`
- `assets/style.css` : feuille de style unique (thèmes clair et sombre)
- `assets/site.js` : compte à rebours, filtres, menu mobile (facultatif : le site reste lisible sans JavaScript)
